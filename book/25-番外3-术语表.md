# 番外 3｜术语表

> CatBuddy 专栏的配套工具文。专栏中出现的技术术语简明解释——遇到不熟的词来这查。

---

## A

**Agent**：能自主执行多步任务的 AI 程序。不只是"一问一答"，而是"收到目标 → 自主探索 → 多步操作 → 给出结果"。在 CatBuddy 中专指运行在 Desktop 上的 Agent Loop。

**Agent Loop**：Agent 的核心循环，在 Idle → Thinking → Acting → Saving 四种状态间切换。详见第 5 篇。

**API Key**：调用 AI 服务（Anthropic/OpenAI/DeepSeek）的凭证。CatBuddy 不自带 Key，用户需要自己提供。

## G

**Gateway**：CatBuddy 三层架构中的中继层。Fastify 服务器，只做消息路由和鉴权，不做 AI 推理。详见第 11 篇。

## I

**IPC**：Inter-Process Communication。Electron 主进程和渲染进程之间的通信方式。

## J

**JSONL**：JSON Lines 格式。每行一个独立 JSON 对象，CatBuddy 用它存储聊天记录。详见第 9 篇。

**JWT**：JSON Web Token。Gateway 鉴权后签发的令牌，后续请求带这个令牌证明身份。

## M

**MCP**：Model Context Protocol。由 Anthropic 提出的标准化协议，让 LLM 和外部工具交互。详见第 6 篇。

**Monorepo**：把多个相关包放在同一个 Git 仓库管理。CatBuddy 的 12 个包就是这样组织的。详见第 3 篇。

## S

**Skill**：技能包。把 MCP 原子工具组合成完整工作流（如"生成 PPT"）。详见第 7 篇。

**State Machine（状态机）**：有限状态自动机。Agent Loop 用状态机管理"当前该做什么"的决策逻辑。

## W

**WebSocket**：全双工通信协议。Gateway 和 Desktop/Web 之间通过它保持长连接，实时双向推送消息。

**Workspace**：工作空间。CatBuddy 中通过 `.catbuddy` 文件授权的工作目录，Agent 只能在这个目录范围内操作。
