## 核心原则

1. **单一职责**：一个类/文件只做一件事
2. **开闭原则**：通过接口隔离，新增功能无需修改已有代码
3. **最少知识**：方法只依赖直接相关的数据结构
4. **命名即文档**：变量/函数名应自解释，减少注释依赖
