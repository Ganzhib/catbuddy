> CatBuddy 专栏的配套参考文。整理了专栏中反复出现的核心类型定义——MessageRecord、UIMessage、AgentRunResult、TokenUsage 等。可当工具文收藏，用到时回来查。

---

## 为什么需要这篇？

专栏 21 篇文章里反复出现了几个核心类型。与其在每篇里重复解释字段含义，不如单开一篇集中整理，方便查阅。

## MessageRecord（存储层）

存在 JSONL 文件里的原始消息结构。字段用 `snake_case`，不包含 UI 相关字段。

```
{
  "id": "msg_xxx",
  "thread_id": "thread_xxx",
  "role": "user" | "assistant" | "tool",
  "content": "..." | [...],  // 文本或 ContentBlock 数组
  "created_at": 1718000000,
  "token_usage": { ... }      // 可选，只有 assistant 消息有
}
```

## UIMessage（渲染层）

React 组件渲染用的消息结构。包含 `node` 字段（React 元素）、`isStreaming` 状态。

## AgentRunResult

Agent 一次完整运行的结果，包含输入、输出、token 用量、错误信息。

## TokenUsage

```
{
  "input_tokens": 1234,
  "output_tokens": 567,
  "cache_creation_input_tokens": 0,
  "cache_read_input_tokens": 0
}
```
