## 1. 创建者 — CLI 入口

`cli/commands.py` 的 `serve()`、`gateway()`、`agent()` 三个入口各创建一个 `MessageBus()` 实例。

```python
bus = MessageBus()          # 创建
agent = AgentLoop(bus=bus)  # 传给 Agent
channels = ChannelManager(bus=bus)  # 传给通道管理器
```

## 2. 消费者 — Agent + Channel

| 文件                            | 干什么                                                              |
| ------------------------------- | ------------------------------------------------------------------- |
| `agent/loop.py`               | `bus.consume_inbound()` 拿消息，`bus.publish_outbound()` 发回复 |
| `agent/subagent.py`           | 子代理通过 bus 收发消息                                             |
| `channels/manager.py`         | `bus.consume_outbound()` 拿 Agent 回复 → 路由到正确通道          |
| `utils/webui_turn_helpers.py` | WebUI 专用的 turn 完成通知                                          |

## 3. 生产者 — 15 个通道

```
channels/whatsapp.py    channels/weixin.py     channels/wecom.py
channels/websocket.py   channels/telegram.py   channels/slack.py
channels/qq.py          channels/msteams.py    channels/mochat.py
channels/matrix.py      channels/feishu.py     channels/email.py
channels/discord.py     channels/dingtalk.py
```

每个通道的 `_handle_message()` → `bus.publish_inbound(msg)`，把收到的消息推入队列。

## 4. 基类定义

`channels/base.py` — `BaseChannel.__init__(self, config, bus)` 存 `self.bus`，所有子类继承。

---

**总结**：`MessageBus` 只有一个作用 — **连接通道和 Agent**。通道往里推，Agent 往外拿，ChannelManager 把回复分回正确通道。你的 desktop 目前只有 WebUI 一个通道，所以 bus 闲置。等加上 WhatsApp bridge，bridge 就会是第 3 类（生产者）。
