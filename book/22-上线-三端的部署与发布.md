## 小节规划

### 21.1 Gateway 部署：Docker Compose
Gateway 容器 + MySQL 容器。docker-compose.yml 的结构、环境变量、健康检查。建议的 VPS 最小配置（1C1G 够用吗？）。

### 21.2 Web 部署：静态文件 + CDN
Vite build → dist/ → nginx 或 CDN。SPA 的路由配置（所有路由指向 index.html）。HTTPS 证书（Let's Encrypt）。

### 21.3 Desktop 发版：electron-builder
版本号管理、构建三平台安装包、代码签名、自动更新（electron-updater）。发版流程：beta → stable。

### 21.4 CI/CD 流水线
GitHub Actions：push → lint → test → build → deploy。Gateway 自动部署到服务器，Web 自动部署到 CDN，Desktop 构建产物上传到 Release。
