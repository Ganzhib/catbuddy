
## 改动清单

### 新增文件（`electron/command/`）

```
electron/command/
├── types.ts           # CommandSpec 类型
├── context.ts         # CommandContext + CommandLoopAPI 接口
├── router.ts          # CommandRouter 三层路由表（priority/exact/prefix）
├── builtin.ts         # 注册内置命令 + 元数据
├── index.ts           # 统一导出
└── handlers/
    ├── stop.ts        # /stop
    ├── new.ts         # /new
    ├── status.ts      # /status
    ├── history.ts     # /history
    ├── model.ts       # /model
    ├── compact.ts     # /compact
    └── help.ts        # /help
```

### 修改文件

`electron/agent/loop.ts`：

- 新增 `commands` 属性 + 构造时注册内置命令
- `_state_command()`：**160 行 → 19 行**

### 效果对比

```
改造前：_state_command()
  /stop    → if (raw === "/stop") { ... }
  /new     → if (raw === "/new") { ... }
  /status  → if (raw === "/status" || ...) { ... }
  /history → if (raw === "/history" || ...) { ... }
  /model   → if (raw === "/model" || ...) { ... }
  /compact → if (raw === "/compact") { ... }
  共 160 行

改造后：_state_command()
  构造 CommandContext
  调 this.commands.dispatch(cmdCtx)
  result != null → shortcut
  result == null → dispatch
  共 19 行
```

新增命令只需：新建 `handlers/xxx.ts` + `builtin.ts` 加一行 `router.exact('/xxx', cmdXxx)`，不碰 `loop.ts`。
