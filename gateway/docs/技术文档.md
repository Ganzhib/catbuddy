# catbuddy Gateway（Web ⇄ Gateway ⇄ Desktop）技术文档

> 版本：v2.0（Session WebSocket）  
> 最后更新：2026-05-23

---

## 1. 概述

### 1.1 定位

Gateway 是 **Web 薄客户端** 与 **Desktop Agent 宿主** 之间的中继：Web 负责输入与展示；Agent、本地工具、workspace 仅在 Desktop Electron 主进程执行。

### 1.2 架构

```
┌─────────────┐   HTTP 发消息 + WS 收流   ┌──────────────────┐   WS session    ┌─────────────┐
│  Web 浏览器   │ ◄──────────────────────► │  @catbuddy/     │ ◄──────────────► │  Desktop    │
│ AuthGate +   │                         │  gateway (:18765) │                 │ AgentLoop   │
│ GatewayTransport│                        │  MySQL 会话存储    │                 │ 本地工具     │
└─────────────┘                         └──────────────────┘                 └─────────────┘
```

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| HTTP 发信 | `POST /api/sessions/:key/messages` 可靠入队 |
| WS 推流 | `ui_event` 流式 delta / turn_end 等 |
| 同账号路由 | Web JWT `sub` = Desktop `accountEmail` |
| SDK 对称 | `sdk-web` / `sdk-desktop` 共用 `@catbuddy/shared` 协议类型 |

## 3. Session WebSocket 协议

生产环境 **仅** 使用 Session 信封（`register` / `subscribe` / `ui_event` / `inbound_message` 等），**不使用** MessageFrame（`push` / `ack`）。

### 3.1 角色注册

**Web**

```json
{ "type": "register", "role": "web", "deviceId": "web-xxx", "token": "<JWT>" }
```

**Desktop**

```json
{
  "type": "register",
  "role": "desktop",
  "deviceId": "desktop-xxx",
  "token": "<GATEWAY_SECRET>",
  "accountEmail": "user@example.com"
}
```

### 3.2 主要消息类型

| 方向 | type | 说明 |
|------|------|------|
| C→S | `subscribe` / `unsubscribe` | 订阅 `sessionKey`（如 `desktop:chatId`） |
| C→S | `ui_event` | Desktop → Gateway → Web（流式 UI） |
| C→S | `sessions_sync` | Desktop 推送会话列表 |
| C→S | `thread_snapshot` | Desktop 推送完整 thread |
| S→C | `inbound_message` | Gateway → Desktop（Web 发来的用户消息） |
| S→C | `create_session` | Web 新建会话时通知 Desktop |
| S→C | `request_sessions` / `request_thread` | Gateway 向 Desktop RPC |
| S→C | `sync_push` | Desktop 连接后 Gateway 下发缓存 |
| S→C | `ui_event` | Gateway → Web |

### 3.3 HTTP API（Web）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sessions/:sessionKey/messages` | 发用户消息（转发 Desktop） |
| GET | `/api/sessions` | 会话列表 |
| GET | `/api/webui-thread?key=` | 历史 thread |
| POST | `/api/sessions` | 新建会话 |
| GET | `/webui/bootstrap` | Web 启动配置 |

## 4. 核心服务端模块

### 4.1 `GatewayStateService`

- `deviceIdByAccountEmail`：同邮箱 Web ↔ Desktop 绑定
- `handleWebInbound`：写 MySQL 用户消息 → WS `inbound_message` 到 Desktop
- `broadcastUiEvent`：Desktop `ui_event` → 已订阅 Web 连接（多租户过滤）
- `pickDesktopForWebToken`：按 JWT 邮箱选 Desktop
- 离线时 `emitOfflineAssistantReply` 经 WS 推系统提示

### 4.2 `ws-session.ts`

单一路径 `/ws`：解析 JSON → `register` / `subscribe` / `ui_event` / `sessions_sync` 等。

### 4.3 鉴权

| 端 | 凭证 |
|----|------|
| Web | 邮箱登录 JWT（`typ: gateway_web`） |
| Desktop | `GATEWAY_SECRET` + `accountEmail`（与 Web 同邮箱） |

生产须开启邮箱校验；开发可用 `GATEWAY_AUTH_DEV_BYPASS`。

### 4.4 存储

MySQL：会话元数据、owner、消息摘要；Desktop JSONL 为执行真相源，经 `thread_snapshot` 回写 Gateway。

## 5. 客户端 SDK

| 包 | 类 | 职责 |
|----|-----|------|
| `@catbuddy/gateway-sdk-web` | `GatewayTransport` | 实现 `AgentTransport`；WS + HTTP |
| `@catbuddy/gateway-sdk-desktop` | `GatewayDesktopClient` | Node `ws`；收 `inbound_message`、发 `ui_event` |

Web UI 入口：`createCatbuddyClient({ transportMode: 'gateway' })`（`AuthGate`）。

Desktop 入口：`apps/desktop/electron/main.ts` 注入 `sessionProvider` 与 `publishInbound`。

共享逻辑：

- Web：`gateway-web-session.ts`（`openGatewayWebSocket`、`postGatewayUserMessage`）
- Desktop：`gateway-desktop-session.ts` + `gateway-desktop-client.ts`

## 7. 端到端示例（发一条消息）

```
1. Web：POST /api/sessions/desktop:abc/messages  (Bearer JWT)
2. Gateway：store.addUserMessage → pickDesktopForWebToken
3. Gateway → Desktop WS：{ type: "inbound_message", sessionKey, content, ... }
4. Desktop：bus.publishInbound → AgentLoop → LLM/工具
5. Desktop → Gateway WS：{ type: "ui_event", event: { event: "delta", ... } }
6. Gateway → Web WS：{ type: "ui_event", sessionKey, event }
7. Web：GatewayTransport → catbuddyClient → Thread UI 更新
```

桌面切换会话时发送 `session_updated` + `scope: "focus"`，Gateway 仅通知同邮箱 Web 连接。
