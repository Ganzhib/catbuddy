# CatBuddy 技术专栏

> **从零构建一个本地优先的 AI 编程助手**——以 Agent 内容引擎为核心，从架构全景到逐层拆解，全面复盘一个生产级桌面 AI 应用的设计与实现。

---

## 📍 写在前面

这个专栏是 CatBuddy 项目的**技术深度复盘**。写它不是为了推广产品，而是因为在整个开发过程中，我们做了很多有意思的架构决策——每一个选择背后都有它的故事、纠结和教训。这些思考如果不写下来，过半年我自己可能都忘了。

**专栏适合谁看？**

- 正在设计或构建 AI Agent 产品的工程师——这里有 21 篇真实的一手经验
- 对"本地优先 + 跨端协同"这类架构模式好奇的技术人
- 想理解 AI 应用"不只是调个 API"到底还做了什么的人

**不需要什么前置知识？**

不需要提前了解 CatBuddy。每篇开头会用一两句话交代背景。有基本的编程概念（知道前端、后端、数据库是干嘛的）就够。

## 写作原则

1. **每篇独立可读**——掘友可能从搜索引擎直接点进来，不需要从头追
2. **架构图驱动**——能用图说清楚的概念不堆代码
3. **跟掘友聊天，不是写论文**——专业但亲切，有干货有吐槽
4. **问题驱动**——每篇以真实痛点开篇，讲"为什么"而不只讲"是什么"
